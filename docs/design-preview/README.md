# 熊猫投稿 · 设计方案 01

独立 HTML 交互原型，正式应用源码未修改。支持示例数据和本机真实数据两种预览。

当前视觉以用户提供的「熊猫投稿-配色方案.html」中的“熊猫黑白”为准，已收起早期配色比较选项。

## 本机真实数据预览

在项目根目录运行：

```sh
python3 docs/design-preview/serve_local.py --port 4318
```

访问 http://127.0.0.1:4318/docs/design-preview/ 。服务默认只读打开本机 `~/Library/Application Support/com.novelsub.desktop/novelsub.sqlite`，也可通过 `--db /absolute/path/to/database.sqlite` 指定数据库。

- 只监听 127.0.0.1，且只提供白名单内的预览静态资源与内存数据接口。
- 启动时在一致的只读事务中读取一份快照，关闭数据库连接后提供预览。
- 字段白名单包含作品资料、编辑、编辑组、邮箱地址/笔名、投递记录、回复正文、统计所需的失败事件；不读取邮箱授权码、稿件附件内容或系统设置。
- 真实数据只存在服务进程与浏览器内存中，不生成 JSON、数据库副本、真实数据截图或其他项目文件；响应禁用缓存。
- 回复以纯文本显示，不加载邮件中的远程图片或脚本。
- 标记、收藏及表单修改只作用于当前页面内存，不调用 Tauri、SMTP、IMAP，不发送邮件，不修改原数据库。刷新页面重置，重启预览服务更新快照。
- 当前真实数据模式的新增、导入导出、系统设置和备份入口仅演示位置，不执行写入。

## 设计方向

- 墨绿 #276650、深墨 #243C35、浅灰绿 #F5F7F6、白 #FFFFFF、柔金 #A37838、边线 #E1E8E3。
- 系统无衬线承载操作与正文；宋体用于作品标题；等宽字体显示时间和进度。
- 工作台优先展示当前活跃计划；没有活跃任务时展示最近投稿和人工回复，不制造虚构运行进度。
- 计划支持真实状态筛选、作品名称搜索和每页 12 条分页，进度对应最近一轮任务，回复按关联作品累计。
- 回复支持人工/自动/过稿分类、作品筛选、全文搜索；每页 10 封，列表和正文独立滚动。人工回复数量是历史总数，不是未读数。
- 编辑库每页 20 条，支持原有编辑组、收藏、收稿类型与姓名/平台/邮箱/备注搜索。
- 邮箱用真实启用状态和投递计数；统计按原软件时间与记录口径计算，失败次数包含重试事件。
- 新建/编辑流程使用真实编辑组、编辑名单、已配置邮箱、原邮件模板与发送间隔，所有操作停留在预览。

本方案用于评审布局与视觉，不能据此删减正式软件现有的多模板维护、群组维护、调度、重试等功能。


## 第二版视觉评审

顶部提供三种方案，在同一份数据和布局上直接比较：

- 石墨蓝：深色导航、白色阅读区、蓝色操作强调（默认）。
- 明亮蓝：浅色导航，适合偏好通透界面的用户。
- 暖白橙：中性暖灰、白色内容、深橙色操作强调。

另有舒适 / 紧凑行距切换，仅保存预览偏好。第二版加深了正文与次要文字，标签统一使用较弱的中性色，避免颜色淹没任务状态。作品标题改用易于扫读的无衬线字体。

编辑库将姓名、平台与邮箱集中在一列，合并后无需为邮箱额外占一列；收稿备注在列表显示摘要，点击可查看完整类型、备注和所属组。表格独立滚动，表头和分页保持可见。真实数据仍只读，正式软件未修改。

回复阅读区将标记过稿与收藏操作放到正文前；识别到“原始邮件”分隔行时默认折叠引用内容，可展开核对，原数据不变。第二版已检查桌面和 390px 窄窗口，窄窗口表格在自己的区域横向滚动。


## 第三版：编辑资料维护与独立编辑组

根据用户明确优先事项“快速修改邮箱、类型和收稿备注”，编辑模块改为：

- 编辑库与编辑组分别使用 `#editors`、`#groups`，左侧导航独立。
- 编辑库保留专门的邮箱、类型、备注列。点击“编辑”或双击单元格启动行内编辑；Tab 切换、⌘/Ctrl+Enter 保存、Esc 取消。
- 保存时检查姓名、邮箱格式和邮箱重复。修改尚未保存时阻止切换其他列表，避免静默丢失。
- 姓名可打开右侧资料编辑面板，点击备注可直接启动行内编辑，维护姓名、平台、邮箱、收稿/拒收类型与完整备注。
- “资料待完善”筛选缺少收稿类型或备注的记录；“本次修改”集中查看当前页面的编辑结果。
- 批量选择支持跨页保留、加入多个编辑组、收藏。
- 编辑组支持新建、重命名、搜索、添加成员、单个/批量移出，移出后可撤销。移出或删除编辑组不会删除编辑库记录。
- 这一模块的修改使用页面内存中的数据副本；刷新会恢复本地快照，不写入数据库，不影响其他模块或真实发送任务。

参考交互模式（按投稿场景重新设计，并非复刻视觉）：
- HubSpot：筛选视图、记录预览、批量管理。https://knowledge.hubspot.com/records/view-and-filter-records
- Google 通讯录：联系人资料与组成员关系分离，选择多人后统一加入或移出组。https://support.google.com/contacts/answer/30970?hl=zh-Hans

### 收稿标签多选

编辑库常用收稿标签直接平铺，可同时选择多个、单独取消或一键清空。“更多标签”支持搜索完整词表并勾选。默认匹配任意所选标签，也可切换为同时满足全部标签。筛选与平台、搜索词叠加，切换时回到第一页。已用真实数据验证“短篇 + 古言”：任意匹配 140 位，同时满足 16 位。
